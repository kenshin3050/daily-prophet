【Visual Studio Code 1.133正式リリース。プロンプトを見失わない固定スクロール、ローカルHTMLファイルの自動リロード、ClaudeとCopilotの混在可能など新機能】
マイクロソフトは、オープンソースの「コードエディタ（プログラムのコードを書くためのソフトウェア）」である「Visual Studio Code（VS Code）」の最新版1.133を正式リリースしました。今回のアップデートでは、AIへの「プロンプト（AIに指示を出すためのテキスト入力）」を見失わない固定スクロール機能や、ローカルHTMLファイルの自動リロード機能が追加されています。さらに、「Claude（Anthropic社が開発したAIアシスタント）」と「Copilot（GitHubとOpenAIが開発したAIコーディングアシスタント）」といった複数のAIツールを混在させて利用できるようになりました。

URL: https://www.publickey1.jp/blog/26/visual_studio_code_1133htmlclaudecopilot.html

【ローカルで動かせる「Qwen3.8-27B」が無償公開、一部ベンチマークでClaude Opus 4.6 Max超え】
アリババのQwenチームが、270億「パラメータ（AIモデルの性能を決定する数値）」を持つ「AIモデル（人工知能のアルゴリズムやデータ構造を学習させたもの）」である「Qwen3.8-27B」を無償公開しました。このモデルは、Apache License 2.0で「ウェイト（AIモデルの学習済みデータ）」が公開されており、手元のPCに導入可能な「オープンウェイトモデル（学習済みのAIモデルの重み（ウェイト）が公開され、自由に利用・改変できるモデル）」です。一部の「ベンチマーク（ソフトウェアやシステムの性能を比較評価するためのテスト）」では、Anthropicの高性能モデル「Claude Opus 4.6 Max」を上回る性能が報告されています。
出典: GIGAZINE
URL: https://gigazine.net/news/20260817-qwen3-8-27b/
